## Simple Todo Application in React Code.

Features :

- Create a Todo
- See Exixting Todo
- Mark the todo is completed or not.

## Steps in Creating a project.

1. Create a backend folder.
2. Initialize a node project.
3. Create a backend folder & Run : npm init & fill the data.
4. Run : npm install express , [Install all express library].
5. Run : npm install jsonwebtoken , [Install particular library for json].
6. Create a index.js file & write a structure code.
